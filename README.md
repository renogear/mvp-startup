## Scope

This is a San Diego County extraction baseline. No San José rules were applied, no real compliance checks were activated, and the report does not certify code compliance or permit approval. The workflow uses actual drawing evidence and retains human corrections separately from original extraction. Text evidence boxes do not establish room boundaries or physical opening locations.

This branch contains delivery artifacts only. It does not include application source, credentials, local sessions, or the workbench database.
