PermitPilot — Interactive browser prototype

Open PermitPilot.html in Chrome or Edge. No installation, login, internet connection, terminal or server is required after downloading.

The actual San Diego County Plan F reference sheet A1 (source PDF page 5) opens automatically on first use. Click an annotation or evidence row to inspect it. Confirm or correct extracted facts. Use Export review for a PDF and Structured JSON for a data backup. All reviews lets you upload your own PDF, PNG or JPG. Embedded PDF text extraction is supported; scanned text/image OCR is unavailable.

When browser storage is available, originals and changes are saved using IndexedDB. If the browser blocks storage, a prominent Temporary session notice appears; export before closing because that session is not saved. Clearing browser storage, changing browsers, or moving to a different origin may make saved records unavailable. Export important work. Processing runs while this tab is open. No documents are sent to a server.

This is a browser-only prototype, separate from the full-stack application's authentication and organization features. There is no AI service or active building-code compliance rule. Printed dimensions and room labels are candidates for human review, not verified physical measurements or room boundaries. San Jose rules never apply to this San Diego reference.
